# Angular Document Editor - Set Track Changes Revision Colors

## Overview

This sample demonstrates how to customize and set track changes revision colors in the **Syncfusion Angular Document Editor** component. Users can dynamically select colors for different types of revisions:

- **Insertion Color**: Customize the color for text insertions
- **Deletion Color**: Customize the color for text deletions
- **Inserted Row Color**: Customize the color for inserted table rows
- **Deleted Row Color**: Customize the color for deleted table rows

**Available Color Options**: By Author, Blue, Red, Pink, Yellow

## Steps to Run the Sample

1. **Navigate to the project directory**
   ```bash
   cd angular-docx-editor-track-changes-sample
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```
   Or using Angular CLI:
   ```bash
   ng serve
   ```

4. **Open in browser**
   ```
   http://localhost:4200
   ```

## Usage

Once the application is running:
- Select desired revision colors from the dropdown menus in the right-side panel
- Click the **Apply** button to apply the changes to the document
